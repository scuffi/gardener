# Changesets

Each file here describes a change to `@scuffi/gardener` that users will notice. Add one with
`pnpm changeset`. The Release workflow turns pending changesets into the Version Packages pull
request; see [Cutting a release](../docs/onboarding.md#cutting-a-release-gardener-maintainers).

Write the entry for the people running Gardener: what changed, and what they need to do.
